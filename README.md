# Notes App - Тестовое задание для Secunda

Приложение для управления заметками с todo list, реализованное на Nuxt 4 с использованием Composition API.

## 📌 Описание

Notes App — это web приложение для создания, редактирования и управления заметками с todo-листами.

Особенности:

- Полная поддержка undo/redo

- Подтверждение всех деструктивных действий через модальные окна

- Автоматическое сохранение данных в localStorage

- Адаптивный дизайн и кросс-браузерность

## 🛠 Технологический стек

- Nuxt 4 — приложение на базе Vue 3 + Composition API

- Pinia — управление состоянием

- TypeScript — полная типизация компонентов и данных

- VueUse — композаблы (useRefHistory) для undo/redo

- Sass/SCSS — стилизация

- ESLint + Prettier — линтинг и автоформатирование

## 📁 Структура проекта

```bash
app/
├── components/       # Переиспользуемые компоненты
│   ├── layout/       # Макеты и обертки страниц
│   ├── note/         # Карточки и сетки заметок
│   ├── todo/         # Элементы задач
│   └── ui/           # UI: кнопки, модалки, иконки
├── pages/            # Страницы
│   ├── index.vue     # Главная
│   └── edit/[[id]].vue # Редактирование заметки
├── stores/           # Pinia stores
│   ├── notes.ts      # Состояние заметок
│   ├── noteEdit.ts   # Редактирование + история undo/redo
│   └── settings.ts   # Настройки приложения
└── styles/           # Глобальные стили

shared/
└── types/            # Общие TS типы
```

## 🚀 Быстрый старт

### 🔧 Для разработки

```bash
# Клонируем репозиторий
git clone https://github.com/vaneksamoylov/secunda-nuxt-app.git
cd secunda-nuxt-app

# Устанавливаем зависимости
npm install

# Запускаем dev-сервер
npm run dev
```

➡ Приложение будет доступно по адресу: http://localhost:3000

### 🏭 Production через Docker

```bash
# Сборка и запуск через Docker Compose
docker-compose up --build
```

- После запуска доступно по http://localhost

## 📋 Техническое задание

### Главная страница

- Список всех заметок

- Для каждой заметки:
  - Заголовок

  - Первые задачи (без возможности редактирования)

- Действия:
  - 🆕 Создать заметку

  - ✏️ Редактировать

  - 🗑 Удалить (с модальным подтверждением)

### Страница редактирования

- Редактирование заголовка и задач

- Управление задачами:
  - ➕ Добавить

  - ❌ Удалить

  - ✏️ Редактировать

  - ✅ Отметить как выполненную

- Действия с заметкой:
  - 💾 Сохранить

  - ↩️ Отмена редактирования (с подтверждением)

  - 🗑 Удалить (с подтверждением)

  - ⎌ Undo / Redo (Ctrl+Z / Shift+Ctrl+Z)

## 📝 Особенности реализации

- Состояние приложения: Pinia + localStorage

- Undo/Redo: useRefHistory из VueUse

- Модальные окна: Все подтверждения через UiModal

- Переиспользуемые компоненты:
  - UiButton, UiModal, NoteCard, NoteGrid, TodoItem, иконки

- Адаптивность: Flexbox + Grid + media queries

- Типизация: Полная TypeScript типизация для компонентов и данных

- UX: Hover эффекты, плавные transitions, визуальная обратная связь, интуитивная навигация
