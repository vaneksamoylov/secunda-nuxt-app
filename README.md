# Notes App - Тестовое задание для Secunda

Приложение для управления заметками с todo list, реализованное на Nuxt 4 с использованием Composition API.

## 📋 Описание

Приложение позволяет создавать, редактировать и удалять заметки. Каждая заметка содержит заголовок и список задач (todo items). Реализована поддержка undo/redo операций, валидация данных и сохранение в localStorage.

## ✨ Основные возможности

- ✅ Создание, редактирование и удаление заметок
- ✅ Управление задачами внутри заметок (добавление, удаление, редактирование, отметка выполнения)
- ✅ Undo/Redo функциональность (Ctrl+Z / Shift+Ctrl+Z)
- ✅ Подтверждение деструктивных действий
- ✅ Автосохранение в localStorage
- ✅ Адаптивный дизайн

## 🛠 Технологический стек

- **Nuxt 4** - фреймворк на базе Vue 3
- **Pinia** - управление состоянием
- **TypeScript** - типизация
- **VueUse** - композаблы (useRefHistory для undo/redo)
- **Sass/SCSS** - стилизация
- **Composition API** - подход к написанию компонентов

## 🚀 Быстрый старт

### Установка для разработки

1. Клонируйте репозиторий:

```bash
git clone https://github.com/vaneksamoylov/secunda-nuxt-app.git
cd secunda-nuxt-app
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите dev сервер:

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`

### Production сборка

1. Соберите проект:

```bash
npm run build
```

2. Запустите через Docker:

```bash
docker-compose up
```

## 📝 Техническое задание

### Главная страница

- Отображение списка всех заметок
- Для каждой заметки показывается заголовок и первые несколько задач (без возможности редактирования)
- Действия:
  - Переход к созданию новой заметки
  - Переход к редактированию
  - Удаление (с подтверждением)

### Страница редактирования

- Редактирование заголовка заметки
- Управление задачами (добавление, удаление, редактирование, отметка выполнения)
- Действия с заметкой:
  - Сохранение изменений
  - Отмена редактирования (с подтверждением)
  - Удаление (с подтверждением)
  - Undo (Ctrl+Z)
  - Redo (Shift+Ctrl+Z)
